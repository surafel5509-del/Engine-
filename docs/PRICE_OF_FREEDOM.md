# Price of Freedom

**Price of Freedom** is an editable S Engine sample project: a 2D top-down prison-escape immersive sim with a real-time prison clock, systemic guard perception, relationships, contraband searches, health/energy pressure, evidence gathering, and five viable escape routes.

## Open it

1. Start S Engine and create a project from **Price of Freedom (2D Prison Escape)**.
2. Open `Menu` and press **BEGIN YOUR CASE**.
3. The entire game is copied into the project: `Prison.scene.json`, JavaScript behaviours, animations, shaders, generated sprites, a custom mobile control layout, sounds and music.
4. Use the editor’s **UI Creator**, **Controls**, **Texture/Sprite Studio**, or **Script Editor** to change the project without modifying the engine.

The Input layer now exposes these actions alongside the existing shooter, racing, and builder controls. `PFPlayer.js` requests this project’s saved **Price of Freedom** mobile layout with `input.setControls("project")`.

## Systems in the project

- **Clock & schedule:** Day one begins at 06:45. The prison clock follows real time (60 seconds of play advances one prison minute); the UI displays wake, roll-call, work, lunch, dinner and lights-out periods.
- **Health & energy:** sprinting drains energy, resting restores both, coffee restores energy, medkits restore health, and a health collapse forces hospital time.
- **Suspicion & search:** guards and cameras build sight over time. Contraband searches can occur after suspicion rises. Capture causes lockdown, lost knowledge, health damage and a lost day.
- **Social simulation:** six named prisoners offer distinct favors. Help all six to gain five allies for the helicopter route. Sergeant Tesfaye accepts coffee for a key.
- **Knowledge:** maps, guard information, the terminal code, tools and the case evidence contribute knowledge to the HUD.
- **Case evidence:** every escape checks for the evidence file from the Library—escaping is not enough without proof.
- **Guard AI:** `PFGuard.js` defines five patrol routes and two stationary camera sentries. Guards perceive, alert, pursue and capture.
- **Custom art and rendering:** `Prisoner.png`, `PrisonGuard.png`, `SecurityCamera.png`, `Evidence.png`, `Rope.png`, `PrisonGate.png`, and `PrisonMap.png` are generated by the built-in Asset Library. `PrisonPulse.glsl` is used by pickups and cameras; `PrisonNoir.glsl` gives the camera a cold, vignetted post-process grade.
- **Animation:** custom `PrisonerWalk.anim` (8-frame loop) and `PrisonerRun.anim` (6-frame loop) are generated in the project and driven by `PFPlayer.js`.

## Escape routes

All routes are implemented in `PFGame.js` and can be attempted from their marked points after securing the **case evidence**:

| Route | Location | Requirements |
| --- | --- | --- |
| Main Gate | South gate | Chief’s key, keycard, security code, bypass machine |
| Tunnel | South-west dig spot | Spoon, shovel, hammer, rope, map, darkness |
| Wall | East outer wall | 3 rope, grappling hook, gloves, quiet shoes, an ally |
| Helicopter | South-west roof access | 5 allies, map, bypass machine, forged pass |
| Sewer | East hatch | Flashlight, mask, rope, gloves, an ally |

## Smoke test

`EngineGamesTest.priceOfFreedomBootsWithEditableSystems` builds the template, verifies scenes/assets/controls, starts from the menu, enters the prison, dismisses the intro, and asserts that the player, sewer route, UI and clock initialize without script errors.
